# AI-BEGONE
BROWSER EXTENSTION REMOVES AI OVERVIEWS AND AI SLOP, HELPING SAVE EARTH'S RESOURCES

It works by detecting your Google searches and instantly adding a specific parameter (`&udm=14`) to the URL in the background. This seamlessly forces the search engine into the "Web" tab, completely stripping out AI Overviews, videos, and shopping widgets to give you a clean list of classic links.

## How to Install Manually

If you want to run this extension, follow these steps:

1. **Download the files:** Make sure you have the extension folder (containing `manifest.json`, `background.js`, and `logo.png`) saved somewhere easy to find on your computer.
2. **Open the Extensions page:** Open Google Chrome, type `chrome://extensions/` into your address bar, and hit Enter.
3. **Turn on Developer Mode:** Look in the top-right corner of the Extensions page and turn on the toggle switch for **Developer mode**.
4. **Load the code:** Click the **Load unpacked** button that appears in the top-left corner of the page.
5. **Select the folder:** Browse your computer, select the folder containing your extension files, and click "Select Folder".

That's it! The extension is now installed and active. Try making a regular Google search to see it instantly jump to the clean Web tab.
